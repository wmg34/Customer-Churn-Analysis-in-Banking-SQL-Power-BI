Customer Churn Analysis in Banking – SQL & Power BI
📌 Project Overview
This project analyzes customer churn in the banking industry using SQL (SSMS) and Power BI. The goal is to identify key churn drivers and provide data-driven retention strategies to enhance customer loyalty and reduce attrition.

📊 Data Sources & Structure
The analysis is based on customer data from multiple sources:

ActiveCustomer.xlsx
Bank_Churn.csv
CreditCard.xlsx
CustomerInfo.csv
ExitCustomer.xlsx
Gender.xlsx
Geography.xlsx
For detailed attribute explanations, refer to the Business Requirement Document.docx.

🔍 Key Insights & Findings
High churn in November: 429% higher than February, making it a critical focus for retention.
Predictable churn trends: A strong correlation exists between churn in the current and past months.
Gender disparity: More female customers leave the bank than male customers.
Significant churn spike in November: The highest month-over-month increase of 277 customers.
🚀 Tools & Techniques Used
✅ SQL (SSMS): Writing queries to extract and analyze bank churn data.
✅ Power BI: Creating interactive dashboards and insights to inform business decisions.

💡 Business Impact for Banks
This analysis helps banks:
🔹 Identify at-risk customers and intervene early.
🔹 Develop targeted retention strategies to minimize customer loss.
🔹 Improve customer engagement through data-driven decision-making.

📂 Getting Started
Download Power BI Desktop.
Clone this repository to your local machine.
Open the .pbix file in Power BI Desktop.
Connect to the datasets using the data dictionary.
Explore interactive dashboards and extract insights for retention strategies.
⚡ This project uses sample data, but you can replace it with real bank data for deeper insights.
